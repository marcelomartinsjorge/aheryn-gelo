# Aheryn: o hino do gelo
Minigame do Capítulo I de *As Quatro Vontades*.

- `index.html`, `style.css`, `game.js`: o jogo (game.js é gerado de `src/main.js`)
- `src/beats.json`: batidas da música (as runas nascem no compasso)
- Dificuldade: bloco `CONFIG` no topo de `src/main.js`. A dificuldade segue a barra, não o relógio.
- Para testar no PC: `jogar.bat` (precisa do Node instalado)
